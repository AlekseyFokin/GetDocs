Часть проекта, опубликована в ознакомительных целях без ключевой звависимости( RMI библиотеки). Весь проект представляет собой бот, который открывает программу документооборота на участке мирового суда, имитирует работу с интерфейсом с помощью JNA, нажимает кнопки, выбирает рейдиобоксы, вводит пароль и т.д.
По каждой выполненной операции шлет краткий отчет на RMI server. Цель - выгрузить с помощью штатного интерфейса программы XML файл, зазиповать его и отправить по ftp на удаленный сервер.
